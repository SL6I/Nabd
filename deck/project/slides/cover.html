Nabd (نبض, “pulse”) is an autonomous SRE agent built for Challenge 1, Agentic Recovery of a Failing System. It watches a live store, finds what broke, including failures that never raise an alert, fixes the cause inside explicit safety limits, repairs the damage to the data and the money, and proves the store recovered. Built solo by Sultan Alaqili.
