MEDIAN RECOVERY

Nabd runs the loop a senior on-call engineer runs. Detect: Prometheus alerts, a memory forecast that fires before a crash, and Mizan for silent failures. Triage: a dependency graph separates root causes from the symptoms they cause. Investigate: read-only tools over metrics, Drain3-compressed logs, deploy history, Redis and Postgres internals and network probes. Hypothesize: a router picks the brain; the core engine matches known signatures at zero tokens, memory reuses a fix that worked, and the LLM is called only when the incident is new or tangled, and only proposes. Skeptic: every hypothesis is challenged before anything is touched. Act, then verify with three clean synthetic checkouts, and report in English and Arabic. Median recovery in the benchmark: about 55 seconds.
