SULTAN ALAQILI · CHALLENGE 1

To sum up: most agents check whether the system has a pulse. Nabd checks whether the books balance. It finds the failures that never alert, fixes them inside explicit limits, repairs the damage to data and money, and proves the recovery. To run it: docker compose up -d --build, open localhost:7000 and break anything from the menu. The core engine needs no LLM key; an Anthropic-compatible key enables the LLM path for new incidents. Everything else, every table and every run, is in the README and eval/results.
